# Bridging adults: research portfolio

Eleven linked research projects on youth opportunity, mentoring and economic mobility, built
from public data that anyone can download without an account. Each project lives in its own
repository and rebuilds from scratch.

- **[Key takeaways](docs/key-takeaways.md):** what we expected, what turned out true or false,
  and what it means for programs.
- **[Synthesis](docs/synthesis.md):** findings across projects and readiness notes.
- **[Data sources](docs/data-sources.md):** verified no-login datasets and the ones ruled out.
